Cryptography provides tools for confidentiality, integrity, authenticity, and trust. This path explains what each primitive guarantees—and just as importantly, what it does not.

## What you will learn

- The security goals behind common cryptographic tools
- How symmetric and asymmetric encryption differ
- Why hash functions are useful for integrity
- How digital signatures establish authenticity

<Callout type="warning" title="Use trusted implementations">
  Educational visualizations explain concepts. Production systems should always use established cryptographic libraries and reviewed protocols.
</Callout>

## Suggested sequence

Start with encryption and key terminology. Continue to hashing, symmetric ciphers, public key systems, and digital signatures.
