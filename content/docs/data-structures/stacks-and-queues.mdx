Stacks and queues are access patterns built on top of another structure. Their constraints make state transitions predictable and algorithms easier to reason about.

## Stack: last in, first out

`push` adds to the top and `pop` removes from the top. Call stacks, undo history, and depth-first search all use this pattern.

## Queue: first in, first out

`enqueue` adds at the back and `dequeue` removes from the front. Task scheduling and breadth-first search use this pattern.

| Structure | Add | Remove | Typical use |
| --- | --- | --- | --- |
| Stack | Top | Top | Backtracking |
| Queue | Back | Front | Fair scheduling |

<Callout type="info" title="Implementation detail matters">
  A queue backed by a dynamic array should avoid shifting every element on each dequeue. A circular buffer or head index keeps the operation efficient.
</Callout>
