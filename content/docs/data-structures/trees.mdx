A tree connects nodes through parent–child relationships. It has one root and no cycles, so every node has exactly one path from the root.

## Essential vocabulary

- A **leaf** has no children.
- A node's **depth** is its distance from the root.
- The tree's **height** is the longest path from a node to a leaf.
- A **subtree** is a node together with all of its descendants.

## Traversal choices

Depth-first traversal explores a branch before returning. Breadth-first traversal visits nodes level by level. The right choice depends on whether your question concerns paths, ordering, or distance from the root.

<Callout type="info" title="Balanced versus skewed">
  A balanced search tree can keep lookup near `O(log n)`. A badly skewed tree may behave like a linked list and fall to `O(n)`.
</Callout>
