## More than code

Code tells a computer what to execute. Understanding tells **you** why each step exists, which tradeoff it creates, and when another approach would work better.

## What you will build

### A foundation for reasoning

You will learn to inspect an operation, estimate its cost, trace its state, and explain why it is correct. Those skills transfer between languages and problem domains.

### A practical learning path

The journey begins with complexity and linear structures, continues through trees and graphs, then connects those structures to searching and sorting algorithms.
