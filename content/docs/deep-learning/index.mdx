Deep learning builds layered functions that transform raw inputs into useful representations. This path makes those layers visible—from a single neuron to modern architectures.

## What you will learn

- How tensors move through a network
- Why activation functions are necessary
- How gradients are calculated and propagated
- When CNNs, recurrent models, and transformers are appropriate

<Callout type="info" title="Learning approach">
  Network diagrams reveal active paths, tensor shapes, and parameter updates without hiding the underlying mathematics.
</Callout>

## Suggested sequence

Begin with neurons and forward propagation. Add activation functions and loss, then study backpropagation before moving into specialized architectures.
