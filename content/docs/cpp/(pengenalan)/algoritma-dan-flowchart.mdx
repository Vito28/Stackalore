## Apa itu algoritma?

Sebelum menulis kode, seorang programmer harus tahu **langkah-langkah** untuk menyelesaikan masalahnya. Rangkaian langkah inilah yang disebut algoritma.

<Callout title="Definisi">
  **Algoritma** adalah urutan langkah yang logis, sistematis, dan terbatas untuk menyelesaikan suatu masalah.
</Callout>

Tanpa sadar, kamu memakai algoritma setiap hari. Contohnya saat memasak mie instan:

1. Rebus air hingga mendidih.
2. Masukkan mie, tunggu 3 menit.
3. Tuang bumbu ke piring.
4. Tiriskan mie, lalu campur dengan bumbu.
5. Sajikan.

Urutannya penting. Jika langkah 4 dikerjakan sebelum langkah 1, hasilnya tidak masuk akal. Komputer bahkan lebih "kaku" daripada manusia: ia hanya mengerjakan **persis** apa yang diperintahkan, sesuai urutan.

## Ciri algoritma yang baik

Menurut Donald E. Knuth, algoritma yang baik memiliki lima ciri:

| Ciri | Artinya | Contoh pelanggaran |
| --- | --- | --- |
| **Finite** (berhingga) | Harus berhenti setelah sejumlah langkah. | "Ulangi terus selamanya." |
| **Definite** (jelas) | Setiap langkah tidak boleh ambigu. | "Tambahkan garam secukupnya." Berapa itu secukupnya? |
| **Input** | Memiliki nol atau lebih data masukan. | — |
| **Output** | Menghasilkan minimal satu keluaran. | Algoritma yang tidak menghasilkan apa pun. |
| **Effective** (efektif) | Setiap langkah bisa benar-benar dikerjakan. | "Tuliskan semua bilangan prima." Jumlahnya tak terhingga. |

## Tiga cara menuliskan algoritma

Algoritma yang sama bisa ditulis dengan tiga cara. Kita pakai satu masalah sederhana: **menghitung luas persegi panjang**.

### 1. Bahasa alami (deskriptif)

Ditulis dengan kalimat biasa. Mudah dipahami siapa saja, tetapi bisa bertele-tele dan ambigu.

```txt title="Bahasa alami"
1. Mulai.
2. Minta pengguna memasukkan panjang dan lebar.
3. Kalikan panjang dengan lebar, simpan hasilnya sebagai luas.
4. Tampilkan luas ke layar.
5. Selesai.
```

### 2. Pseudocode

_Pseudo_ berarti "semu". Pseudocode adalah tulisan yang **mirip kode** tetapi tidak terikat aturan bahasa pemrograman tertentu. Bentuk ini paling dekat ke kode asli.

```txt title="Pseudocode"
ALGORITMA LuasPersegiPanjang
DEKLARASI
    panjang, lebar, luas : integer
DESKRIPSI
    READ(panjang, lebar)
    luas ← panjang * lebar
    WRITE(luas)
```

Tanda `←` dibaca "diisi dengan". Artinya nilai di sebelah kanan disimpan ke variabel di sebelah kiri.

### 3. Flowchart

**Flowchart** (diagram alir) menggambarkan algoritma dengan **simbol-simbol** yang dihubungkan anak panah. Alur program jadi mudah dilihat sekilas, terutama saat ada percabangan.

## Contoh: percabangan

Flowchart paling berguna saat algoritma harus **memilih**. Misalnya, menentukan apakah sebuah bilangan **genap** atau **ganjil**.

Idenya: bilangan genap habis dibagi 2, artinya sisa baginya 0. Di pemrograman, sisa bagi dihitung dengan operator modulus `%`. Contohnya `7 % 2` menghasilkan `1`. Operator ini dibahas lengkap di [Operator Aritmatika](/docs/cpp/operator-aritmatika#modulus-sisa-bagi).

<Flowchart
  caption="Flowchart menentukan bilangan genap atau ganjil"
  nodes={[
    { type: 'terminal', label: 'Mulai' },
    { type: 'io', label: 'Input n' },
    {
      type: 'decision',
      label: 'n % 2 == 0 ?',
      yes: [{ type: 'io', label: 'Output "Genap"' }],
      no: [{ type: 'io', label: 'Output "Ganjil"' }],
    },
    { type: 'terminal', label: 'Selesai' },
  ]}
/>

Simbol **keputusan** (belah ketupat) selalu berisi pertanyaan yang jawabannya hanya **Ya** atau **Tidak**. Dari simbol ini keluar dua jalur, dan keduanya bertemu lagi sebelum algoritma selesai.

## Dari flowchart ke kode

Setiap simbol flowchart punya padanan langsung di kode. Tabel ini akan sering kamu pakai di materi-materi berikutnya.

| Simbol | Arti | C++ | Python |
| --- | --- | --- | --- |
| Terminal | Mulai / selesai | `int main() {` … `}` | awal / akhir file |
| Input | Membaca data | `cin >> n;` | `n = int(input())` |
| Proses | Menghitung, mengisi nilai | `luas = p * l;` | `luas = p * l` |
| Output | Menampilkan data | `cout << luas;` | `print(luas)` |
| Keputusan | Memilih jalur | `if (...) { } else { }` | `if ...: else:` |

Berikut kode dari dua flowchart di atas. Kamu belum perlu paham setiap baris. Coba cocokkan setiap baris dengan simbolnya.

```cpp tab="C++"
#include <iostream>
using namespace std;

int main() {                         // Terminal: Mulai
    int panjang, lebar, luas;

    cin >> panjang >> lebar;         // Input
    luas = panjang * lebar;          // Proses
    cout << luas << endl;            // Output

    return 0;
}                                    // Terminal: Selesai
```

```python tab="Python"
# Terminal: Mulai
panjang = int(input())   # Input
lebar = int(input())     # Input
luas = panjang * lebar   # Proses
print(luas)              # Output
# Terminal: Selesai
```

Dan untuk menentukan genap atau ganjil:

```cpp tab="C++"
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;                        // Input n

    if (n % 2 == 0) {                // Keputusan: n % 2 == 0 ?
        cout << "Genap" << endl;     //   Ya
    } else {
        cout << "Ganjil" << endl;    //   Tidak
    }

    return 0;
}
```

```python tab="Python"
n = int(input())          # Input n

if n % 2 == 0:            # Keputusan: n % 2 == 0 ?
    print("Genap")        #   Ya
else:
    print("Ganjil")       #   Tidak
```

<Callout type="info" title="Tentang input">
  Perintah `cin >>` (C++) dan `input()` (Python) dijelaskan lengkap di materi [Input & Output](/docs/cpp/input-dan-output#membaca-input). Di sana kamu juga akan melihat mengapa `cin >> panjang >> lebar` bisa membaca dua angka yang dipisah spasi maupun Enter.
</Callout>

## Tips membuat flowchart

- Mulai dan akhiri dengan **satu** simbol terminal.
- Alur dibaca dari **atas ke bawah**, atau kiri ke kanan.
- Usahakan garis alir **tidak saling bersilangan**.
- Tulis isi simbol dengan singkat dan jelas, misalnya `luas = p × l`, bukan kalimat panjang.
- Setiap simbol keputusan harus punya tepat **dua** jalur keluar: Ya dan Tidak.

## Rangkuman

- **Algoritma** adalah urutan langkah logis untuk menyelesaikan masalah. Algoritma yang baik bersifat _finite_, _definite_, punya _input_ dan _output_, serta _effective_.
- Algoritma bisa ditulis dengan **bahasa alami**, **pseudocode**, atau **flowchart**.
- Flowchart memakai simbol baku: terminal (oval), input/output (jajar genjang), proses (persegi panjang), dan keputusan (belah ketupat).
- Setiap simbol punya padanan langsung di kode C++ maupun Python.

<Soal no={4} level="menengah" judul="Telusuri isi variabel">
  Telusuri pseudocode berikut tanpa komputer.

  ```txt title="Pseudocode"
  ALGORITMA Tebak
  DEKLARASI
      a, b : integer
  DESKRIPSI
      READ(a, b)
      a ← a + b
      b ← a - b
      a ← a - b
      WRITE(a, b)
  ```

  1. Untuk input `a = 7` dan `b = 2`, catat isi `a` dan `b` setelah setiap langkah dalam sebuah tabel. Apa yang ditampilkan?
  2. Ulangi untuk input `a = 10` dan `b = 25`.
  3. Apa sebenarnya kegunaan algoritma ini?

  <Petunjuk>
    `←` mengganti isi variabel, dan nilai lamanya hilang. Di setiap langkah, selalu pakai nilai **terbaru** dari baris tabel sebelumnya.
  </Petunjuk>

  <Pembahasan>
    | Langkah | `a` | `b` |
    | --- | --- | --- |
    | `READ(a, b)` | 7 | 2 |
    | `a ← a + b` | 9 | 2 |
    | `b ← a - b` | 9 | 7 |
    | `a ← a - b` | 2 | 7 |

    Yang ditampilkan adalah `2 7`. Untuk input 10 dan 25, isinya menjadi 35 dan 25, lalu 35 dan 10, lalu 25 dan 10, sehingga yang ditampilkan `25 10`.

    Algoritma ini **menukar isi `a` dan `b`** tanpa variabel ketiga. Kesalahan yang sering terjadi adalah memakai nilai `a` yang lama (7) di langkah `b ← a - b`, padahal `a` sudah berubah menjadi 9.

    ```cpp tab="C++"
    #include <iostream>
    using namespace std;

    int main() {
        int a, b;
        cin >> a >> b;
        a = a + b;
        b = a - b;
        a = a - b;
        cout << a << " " << b << endl;
        return 0;
    }
    ```

    ```python tab="Python"
    a, b = map(int, input().split())
    a = a + b
    b = a - b
    a = a - b
    print(a, b)
    ```
  </Pembahasan>
</Soal>

<Soal no={5} level="menengah" judul="Terbesar dari dua bilangan">

  Di pseudocode, simbol keputusan ditulis dengan `IF`. Perbandingan boleh memakai simbol matematika seperti `>`, `<`, `≥`, `≤`, `=`, dan `≠`.

  ```txt title="Bentuk IF di pseudocode"
  IF kondisi THEN
      langkah jika Ya
  ELSE
      langkah jika Tidak
  ENDIF
  ```

  | Input | Output |
  | --- | --- |
  | `8 3` | `8` |
  | `2 9` | `9` |
  | `5 5` | `5` |

  <Petunjuk>
    Satu keputusan sudah cukup. Pikirkan jalur mana yang dilewati jika `a` dan `b` sama, dan apa yang ditampilkan di jalur itu.
  </Petunjuk>

  <Pembahasan>
    ```txt title="Pseudocode"
    ALGORITMA Terbesar
    DEKLARASI
        a, b : integer
    DESKRIPSI
        READ(a, b)
        IF a > b THEN
            WRITE(a)
        ELSE
            WRITE(b)
        ENDIF
    ```

    <Flowchart
      caption="Flowchart bilangan terbesar dari dua bilangan"

    ```cpp tab="C++"

        int a, b;
        cin >> a >> b;

        if (a > b) {
            cout << a << endl;

            cout << b << endl;
        }

        return 0;
    }
    ```

    ```python tab="Python"

    if a > b:
        print(a)
    else:
        print(b)
    ```

<Soal no={6} level="menengah" judul="Tarif parkir">
  Sebuah tempat parkir memasang tarif Rp5.000 untuk 2 jam pertama, ditambah Rp3.000 untuk setiap jam berikutnya. Tulis **pseudocode** dan **flowchart** yang membaca lama parkir (bilangan bulat, dalam jam, minimal 1) lalu menampilkan biayanya.

  | Input | Output |
  | --- | --- |
  | `1` | `5000` |
  | `2` | `5000` |
  | `5` | `14000` |

  <Petunjuk>
    Keputusannya: apakah lama parkir paling banyak 2 jam? Jika tidak, banyak jam tambahannya adalah `lama - 2`.
  </Petunjuk>

  <Pembahasan>
    ```txt title="Pseudocode"
    ALGORITMA TarifParkir
    DEKLARASI
        lama, biaya : integer
    DESKRIPSI
        READ(lama)
        IF lama ≤ 2 THEN
            biaya ← 5000
        ELSE
            biaya ← 5000 + (lama - 2) * 3000
        ENDIF
        WRITE(biaya)
    ```

    <Flowchart
      caption="Flowchart tarif parkir"
      nodes={[
        { type: 'terminal', label: 'Mulai' },
        { type: 'io', label: 'Input lama' },
        {
          type: 'decision',
          label: 'lama ≤ 2 ?',
          yes: [{ type: 'process', label: 'biaya = 5000' }],
          no: [{ type: 'process', label: 'biaya = 5000 +\n(lama − 2) × 3000' }],
        },
        { type: 'io', label: 'Output biaya' },
        { type: 'terminal', label: 'Selesai' },
      ]}
    />

    Untuk 5 jam, ada 5 − 2 = 3 jam tambahan, jadi biayanya 5000 + 3 × 3000 = 14000. Kesalahan yang sering terjadi adalah mengalikan **seluruh** lama parkir dengan 3000, padahal 2 jam pertama sudah termasuk dalam Rp5.000.

    ```cpp tab="C++"
    #include <iostream>
    using namespace std;

    int main() {
        int lama, biaya;
        cin >> lama;

        if (lama <= 2) {
            biaya = 5000;
        } else {
            biaya = 5000 + (lama - 2) * 3000;
        }

        cout << biaya << endl;
        return 0;
    }
    ```

    ```python tab="Python"
    lama = int(input())

    if lama <= 2:
        biaya = 5000
    else:
        biaya = 5000 + (lama - 2) * 3000

    print(biaya)
    ```
  </Pembahasan>
</Soal>

  <Petunjuk>
    Buat tabel dengan kolom `n` dan "n sama dengan 0?", lalu isi baris demi baris. Untuk `n = 5`, perhatikan apakah `n` pernah bernilai **tepat** 0. Jangan lupa mencoba `n` negatif.

  <Pembahasan>
    **1.** Untuk `n = 6`:

    | `n` di langkah 3 | `n` sama dengan 0? | Yang ditampilkan |

    | 6 | Tidak | `6` |
    | 4 | Tidak | `4` |
    | 2 | Tidak | `2` |
    | 0 | Ya, lompat ke langkah 7 | `Selesai` |

    **2.** Untuk `n = 5`, nilai `n` menjadi 5, 3, 1, -1, -3, dan seterusnya. Nilainya melompati 0 dan tidak pernah tepat 0, jadi algoritma terus menampilkan angka tanpa henti. Ciri yang dilanggar adalah _finite_.

    **3.** Algoritma berhenti hanya jika `n` adalah 0 atau bilangan genap positif. Algoritma tidak pernah berhenti untuk semua bilangan ganjil dan semua bilangan genap negatif, karena `n` terus mengecil dan makin menjauh dari 0.

    **4.** Ganti langkah 3 menjadi "Jika n kurang dari atau sama dengan 0, lompat ke langkah 7." Untuk `n = 6` hasilnya tetap sama. Untuk `n = 5`, yang ditampilkan `5`, `3`, `1`, lalu `Selesai`. Untuk `n` negatif, algoritma langsung menampilkan `Selesai`.

    Dalam flowchart, langkah "kembali ke langkah 3" digambar sebagai panah yang naik kembali ke belah ketupat. Pertanyaannya dibalik menjadi `n > 0 ?` supaya jalur Ya berarti "lanjutkan".

<Soal no={9} level="sulit" judul="Terbesar dari tiga bilangan">
  Eko menulis algoritma untuk menampilkan bilangan terbesar dari tiga bilangan bulat:

  ```txt title="Algoritma Eko"
  1. Mulai.
  2. Baca a, b, c.
  3. Jika a > b dan a > c, tampilkan a.
  4. Jika b > a dan b > c, tampilkan b.
  5. Jika c > a dan c > b, tampilkan c.
  6. Selesai.
  ```

  Eko mencobanya dengan input `3 9 5` dan hasilnya benar, yaitu `9`.

  1. Cari input yang membuat algoritma Eko **tidak menampilkan apa pun**. Ciri algoritma mana yang dilanggar?
  2. Tulis algoritma yang benar dalam pseudocode, lalu gambar flowchart-nya. Algoritmamu harus menghasilkan output berikut.

  | Input | Output |
  | --- | --- |
  | `3 9 5` | `9` |
  | `7 7 2` | `7` |
  | `-4 -1 -8` | `-1` |

  <Petunjuk>
    Untuk bagian 1, coba input yang dua bilangannya sama. Untuk bagian 2, bayangkan memegang "juara sementara": mulai dari `a`, lalu bandingkan dengan `b`, lalu dengan `c`. Bagian `ELSE` pada `IF` boleh tidak ditulis jika jalur Tidak memang tidak melakukan apa-apa.
  </Petunjuk>

  <Pembahasan>
    **1.** Contohnya `7 7 2`. Langkah 3 bernilai Tidak karena `7 > 7` salah. Langkah 4 juga Tidak karena `7 > 7` salah. Langkah 5 juga Tidak karena `2` bukan yang terbesar. Tidak ada yang ditampilkan, jadi ciri _output_ dilanggar. Input `5 5 5` juga gagal dengan cara yang sama.

    Mengganti `>` dengan `≥` juga belum benar. Untuk `7 7 2`, langkah 3 dan 4 sama-sama bernilai Ya, sehingga `7` tampil **dua kali**.

    **2.** Pakai "juara sementara" bernama `terbesar`. Isi awalnya `a`, lalu juara itu ditantang oleh `b` dan `c` secara bergantian.

    ```txt title="Pseudocode"
    ALGORITMA TerbesarDariTiga
    DEKLARASI
        a, b, c, terbesar : integer
    DESKRIPSI
        READ(a, b, c)
        terbesar ← a
        IF b > terbesar THEN
            terbesar ← b
        ENDIF
        IF c > terbesar THEN
            terbesar ← c
        ENDIF
        WRITE(terbesar)
    ```

<Soal no={10} level="sulit" judul="Pemesanan tiket bioskop">
  Rancang algoritma pemesanan tiket bioskop. Inputnya adalah banyak kursi yang masih kosong dan banyak tiket yang dipesan, dalam satu baris. Periksa aturan berikut **sesuai urutan**:

  - **Aturan pertama:** satu pesanan maksimal 5 tiket. Jika lebih, tampilkan `Jumlah tiket tidak valid`.
  - **Aturan kedua:** jika tiket yang dipesan lebih banyak daripada kursi kosong, tampilkan `Kursi tidak cukup`.
  - Jika kedua aturan terpenuhi, kurangi kursi kosong dengan banyak tiket, lalu tampilkan sisa kursi kosong.

  | Input | Output |
  | --- | --- |
  | `40 3` | `37` |
  | `40 7` | `Jumlah tiket tidak valid` |
  | `2 4` | `Kursi tidak cukup` |

  Kerjakan tiga bagian berikut.

  1. Tulis algoritmanya dalam pseudocode.
  2. Susun kasus uji sesedikit mungkin, sehingga **setiap** kemungkinan output muncul minimal sekali. Berapa kasus uji yang dibutuhkan? Lalu tebak output untuk input `3 7`, saat kedua aturan sama-sama dilanggar.
  3. Telusuri algoritmamu untuk input `40 0` dan `40 -3`. Apa yang janggal? Perbaiki algoritmanya.

  <Petunjuk>
    Pilihan bertingkat bisa ditulis dengan `ELSE IF`, seperti rantai pertanyaan: jika ini, tampilkan A; jika bukan tetapi itu, tampilkan B; selain itu, kerjakan C. Untuk bagian 3, tanyakan: apakah ada aturan yang melarang pesanan 0 tiket atau pesanan negatif?
  </Petunjuk>

  <Pembahasan>
    **1.** Aturan diperiksa berurutan, jadi aturan kedua baru diperiksa jika aturan pertama lolos.

    ```txt title="Pseudocode (versi pertama)"
    ALGORITMA PesanTiket
    DEKLARASI
        kursi, tiket : integer
    DESKRIPSI
        READ(kursi, tiket)
        IF tiket > 5 THEN
            WRITE("Jumlah tiket tidak valid")
        ELSE IF tiket > kursi THEN
            WRITE("Kursi tidak cukup")
        ELSE
            kursi ← kursi - tiket
            WRITE(kursi)
        ENDIF
    ```

    **2.** Ada tiga kemungkinan output, dan setiap kasus uji hanya menghasilkan satu output. Jadi dibutuhkan minimal **tiga** kasus uji, misalnya tiga contoh di soal: `40 3`, `40 7`, dan `2 4`. Untuk input `3 7`, aturan pertama sudah dilanggar, jadi outputnya `Jumlah tiket tidak valid`, dan aturan kedua tidak pernah diperiksa.

    **3.** Untuk `40 0`, kedua aturan lolos, lalu algoritma menampilkan `40`, seolah-olah ada pesanan yang berhasil padahal tidak ada tiket yang dipesan. Untuk `40 -3`, hasilnya lebih parah: 40 − (−3) = 43, sehingga kursi kosong **bertambah**. Aturan pertama hanya membatasi tiket dari atas, tidak dari bawah. Perbaikannya, tolak juga pesanan yang kurang dari 1 tiket. `OR` berarti cukup salah satu syarat terpenuhi.

    ```txt title="Pseudocode (sudah diperbaiki)"
    ALGORITMA PesanTiket
    DEKLARASI
        kursi, tiket : integer
    DESKRIPSI
        READ(kursi, tiket)
        IF tiket < 1 OR tiket > 5 THEN
            WRITE("Jumlah tiket tidak valid")
        ELSE IF tiket > kursi THEN
            WRITE("Kursi tidak cukup")
        ELSE
            kursi ← kursi - tiket
            WRITE(kursi)
        ENDIF
    ```

    Kebiasaan memeriksa nilai 0 dan nilai negatif seperti ini akan sangat berguna saat kamu menguji program sungguhan.

    ```cpp tab="C++"
    #include <iostream>
    using namespace std;

    int main() {
        int kursi, tiket;
        cin >> kursi >> tiket;

        if (tiket < 1 || tiket > 5) {
            cout << "Jumlah tiket tidak valid" << endl;
        } else if (tiket > kursi) {
            cout << "Kursi tidak cukup" << endl;
        } else {
            kursi = kursi - tiket;
            cout << kursi << endl;
        }

        return 0;
    }
    ```

    ```python tab="Python"
    kursi, tiket = map(int, input().split())

    if tiket < 1 or tiket > 5:
        print("Jumlah tiket tidak valid")
    elif tiket > kursi:
        print("Kursi tidak cukup")
    else:
        kursi = kursi - tiket
        print(kursi)
    ```
  </Pembahasan>
</Soal>
