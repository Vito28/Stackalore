Selamat datang! Seri ini mengajak kamu belajar pemrograman **dari nol**. Kita mulai dari ide paling dasar, yaitu apa itu bahasa pemrograman dan bagaimana menyusun langkah penyelesaian masalah, lalu pelan-pelan masuk ke penulisan kode C++.

Setiap contoh kode ditulis dalam **C++** dan **Python**. Pilih tab bahasa di atas blok kode. Pilihanmu diingat di semua halaman.

```cpp tab="C++"
#include <iostream>
using namespace std;

int main() {
    cout << "Halo, Stacklore!" << endl;
    return 0;
}
```

```python tab="Python"
print("Halo, Stacklore!")
```

Ikuti materi sesuai nomor. Setiap materi memakai konsep dari materi sebelumnya.

## Cara memakai dokumentasi ini

- **Sidebar kiri** berisi materi yang dikelompokkan per modul, misalnya _C++ Dasar_ atau _Struktur Data_. Klik nama modul untuk membuka atau menutup daftar materinya. Di layar kecil, buka lewat tombol menu di pojok kiri atas.
- **Daftar isi di kanan** menunjukkan subbab di halaman yang sedang dibuka dan posisi bacaanmu sekarang.
- **Kotak Pendalaman** muncul saat sebuah topik butuh penjelasan panjang, misalnya _buffer_, `getline`, atau pointer. Topik itu sengaja dipisah agar alur materi utama tetap ringan. Baca saat kamu penasaran, lalu kembali ke materi.
- **Latihan** di akhir setiap materi berisi 10 soal: 3 mudah, 4 menengah, dan 3 sulit. Petunjuk dan pembahasannya tertutup sampai kamu membukanya, jadi coba kerjakan sendiri dulu.
- Tekan <kbd>Ctrl</kbd> <kbd>K</kbd> untuk mencari materi dari mana saja.

<DeepDive href="/docs/cpp/pendalaman/buffer" kind="konsep" title="Contoh kotak Pendalaman">
  Kotak seperti ini mengarah ke penjelasan yang lebih dalam. Materi utama tetap bisa dipahami tanpa membukanya.
</DeepDive>

  Fokus kita adalah memahami **cara berpikir** pemrograman. C++ dipakai sebagai bahasa utama karena memaksa kita memahami tipe data dan memori. Python ditampilkan sebagai pembanding supaya kamu melihat bahwa konsepnya sama, hanya cara menulisnya yang berbeda.
</Callout>
