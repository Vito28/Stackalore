## Antrean di loket

Di loket tiket, orang yang baru datang berdiri di **belakang** antrean, sedangkan petugas melayani orang yang paling **depan**. Siapa yang datang lebih dulu dilayani lebih dulu, dan tidak ada yang boleh menyela.

**Queue** (antrean) adalah struktur data dengan aturan yang sama: elemen **masuk dari belakang** dan **keluar dari depan**. Aturan ini disebut **FIFO** (_First In, First Out_): yang pertama masuk, yang pertama keluar. Bandingkan dengan [Stack](/docs/cpp/stack) yang LIFO. Stack seperti tumpukan piring, sedangkan queue seperti barisan orang.

Queue ada di mana-mana di dalam komputer: dokumen yang menunggu giliran dicetak, pesan yang menunggu dikirim, dan tombol yang kamu tekan sebelum program sempat membacanya. Karakter yang kamu ketik saat program menjalankan `cin` pun menunggu di <Term href="/docs/cpp/pendalaman/buffer">buffer input</Term> dan dibaca sesuai urutan ketikannya. Nanti, queue juga menjadi inti algoritma [BFS](/docs/cpp/bfs) untuk mencari rute terpendek.

## Operasi queue

| Operasi | Arti |
| --- | --- |
| **enqueue**(x) | Masukkan `x` di belakang antrean |
| **dequeue** | Keluarkan elemen paling depan |
| **front** | Lihat elemen paling depan tanpa mengeluarkannya |
| **back** | Lihat elemen paling belakang |
| **empty** | Periksa apakah antrean kosong |
| **size** | Hitung banyak elemen |

Tabel berikut menunjukkan isi sebuah queue yang awalnya kosong. Isinya ditulis dari depan ke belakang, jadi elemen paling kiri adalah yang berikutnya keluar.

| Langkah | Operasi | Isi queue (depan → belakang) | Hasil |
| --- | --- | --- | --- |
| 1 | enqueue(Ani) | `Ani` | |
| 2 | enqueue(Budi) | `Ani Budi` | |
| 3 | enqueue(Citra) | `Ani Budi Citra` | |
| 4 | front | `Ani Budi Citra` | `Ani` |
| 5 | dequeue | `Budi Citra` | `Ani` keluar |
| 6 | enqueue(Dodi) | `Budi Citra Dodi` | |
| 7 | dequeue | `Citra Dodi` | `Budi` keluar |
| 8 | back | `Citra Dodi` | `Dodi` |

Ani datang pertama dan keluar pertama. Dodi datang terakhir, jadi ia harus menunggu semua orang di depannya.

## Queue di C++ dan Python

C++ menyediakan `queue` dari pustaka `<queue>`. Python memakai `deque` dari modul `collections`.

```cpp tab="C++"
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> q;

    q.push("Ani");                  // enqueue
    q.push("Budi");
    q.push("Citra");
    cout << q.front() << endl;      // Ani

    q.pop();                        // dequeue: Ani keluar
    q.push("Dodi");
    q.pop();                        // dequeue: Budi keluar

    cout << q.front() << " " << q.back() << endl;   // Citra Dodi
    cout << q.size() << endl;                       // 2
    return 0;
}
```

```python tab="Python"
from collections import deque

q = deque()

q.append("Ani")                 # enqueue
q.append("Budi")
q.append("Citra")
print(q[0])                     # Ani

q.popleft()                     # dequeue: Ani keluar
q.append("Dodi")
q.popleft()                     # dequeue: Budi keluar

print(q[0], q[-1])              # Citra Dodi
print(len(q))                   # 2
```

| Operasi | C++ `queue` | Python `deque` |
| --- | --- | --- |
| enqueue | `q.push(x)` | `q.append(x)` |
| dequeue | `q.pop()` | `q.popleft()` |
| front | `q.front()` | `q[0]` |
| back | `q.back()` | `q[-1]` |
| empty | `q.empty()` | `len(q) == 0` |
| size | `q.size()` | `len(q)` |

Sama seperti `stack`, `queue` di C++ tidak bisa diakses dengan indeks, dan `pop()` tidak mengembalikan nilai. Ambil dulu dengan `front()`, baru `pop()`. Di Python, `popleft()` membuang **sekaligus** mengembalikan elemen paling depan.

Python juga punya modul bernama `queue`, tetapi modul itu dirancang untuk program yang menjalankan beberapa tugas sekaligus (_multi-thread_). Untuk antrean biasa, pakai `deque`.

## Kenapa tidak memakai list atau vector saja?

List Python sebenarnya bisa dipakai sebagai antrean: `append(x)` untuk masuk dan `pop(0)` untuk keluar. Hasilnya benar, tetapi lambat untuk data besar. Elemen list tersimpan berurutan di memori, jadi saat elemen pertama dibuang, **semua** elemen lain harus digeser satu posisi ke depan. Dengan 100.000 elemen, satu kali `pop(0)` menggeser hampir 100.000 elemen.

Sebagai gambaran, pada satu komputer uji, mengosongkan list berisi 200.000 elemen dengan `pop(0)` memakan waktu sekitar 2 detik, sedangkan `popleft()` pada `deque` hanya sekitar 0,006 detik. Jika datanya digandakan, waktu `pop(0)` naik kira-kira **empat kali lipat**, sementara `popleft()` hanya dua kali lipat. Angka persisnya bergantung pada komputer, tetapi polanya selalu sama.

Masalah yang sama terjadi di C++ jika kamu membuang elemen pertama vector dengan `v.erase(v.begin())`. `deque` di kedua bahasa dirancang agar menambah dan membuang di **kedua ujung** sama-sama cepat, dan `queue` di C++ memakai `deque` di dalamnya.

## Jebakan: queue kosong

Seperti stack, mengambil dari queue yang kosong adalah kesalahan.

```cpp tab="C++"
queue<int> q;
cout << q.front() << endl;   // ✗ undefined behavior
q.pop();                     // ✗ undefined behavior
```

```python tab="Python"
q = deque()
print(q[0])                  # ✗ IndexError: deque index out of range
q.popleft()                  # ✗ IndexError: pop from an empty deque
```

Saat dicoba dengan `g++`, `q.front()` pada queue kosong justru menampilkan `0` tanpa pesan apa pun. Angka itu tampak wajar, padahal tidak berarti apa-apa. Inilah bahaya [_undefined behavior_](/docs/cpp/pendalaman/undefined-behavior): kesalahannya tidak selalu terlihat. Selalu periksa `empty()` sebelum `front()`, `back()`, atau `pop()`.

## Contoh: simulasi loket tiket

Program berikut menjalankan perintah `DATANG nama` (orang masuk antrean) dan `LAYANI` (petugas melayani orang paling depan).

```cpp tab="C++"
#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    queue<string> antrean;

    for (int i = 0; i < n; i++) {
        string perintah;
        cin >> perintah;
        if (perintah == "DATANG") {
            string nama;
            cin >> nama;
            antrean.push(nama);
            cout << nama << " masuk, panjang antrean " << antrean.size() << endl;
        } else if (perintah == "LAYANI") {
            if (antrean.empty()) {
                cout << "Antrean kosong" << endl;
            } else {
                cout << "Melayani " << antrean.front() << endl;
                antrean.pop();
            }
        }
    }
    return 0;
}
```

```python tab="Python"
from collections import deque

n = int(input())
antrean = deque()

for i in range(n):
    bagian = input().split()
    if bagian[0] == "DATANG":
        antrean.append(bagian[1])
        print(f"{bagian[1]} masuk, panjang antrean {len(antrean)}")
    elif bagian[0] == "LAYANI":
        if len(antrean) == 0:
            print("Antrean kosong")
        else:
            print("Melayani", antrean.popleft())
```

## Contoh: permainan kentang panas

Beberapa pemain duduk melingkar dan mengoper sebuah "kentang panas". Setelah kentang dioper `k` kali, pemain yang sedang memegangnya keluar dari permainan. Permainan berlanjut sampai tersisa satu pemenang.

Lingkaran bisa disimulasikan dengan queue. Pemain paling depan adalah yang sedang memegang kentang. Mengoper berarti mengeluarkan pemain depan lalu memasukkannya lagi di belakang, sehingga kentang berpindah ke pemain berikutnya. Berikut isi queue selama putaran pertama dengan `k = 3`:

| Oper ke- | Isi queue (depan → belakang) |
| --- | --- |
| awal | `Ani Budi Citra Dodi Eka` |
| 1 | `Budi Citra Dodi Eka Ani` |
| 2 | `Citra Dodi Eka Ani Budi` |
| 3 | `Dodi Eka Ani Budi Citra` |

Dodi memegang kentang setelah oper ketiga, jadi Dodi keluar.

```cpp tab="C++"
#include <iostream>
#include <queue>
#include <string>
#include <vector>
using namespace std;

int main() {
    vector<string> pemain = {"Ani", "Budi", "Citra", "Dodi", "Eka"};
    int k = 3;

    queue<string> lingkaran;
    for (string nama : pemain) {
        lingkaran.push(nama);
    }

    while (lingkaran.size() > 1) {
        for (int i = 0; i < k; i++) {               // kentang dioper k kali
            lingkaran.push(lingkaran.front());      // yang depan pindah ke belakang
            lingkaran.pop();
        }
        cout << lingkaran.front() << " keluar" << endl;
        lingkaran.pop();
    }
    cout << "Pemenang: " << lingkaran.front() << endl;
    return 0;
}
```

```python tab="Python"
from collections import deque

pemain = ["Ani", "Budi", "Citra", "Dodi", "Eka"]
k = 3

lingkaran = deque()
for nama in pemain:
    lingkaran.append(nama)

while len(lingkaran) > 1:
    for i in range(k):                          # kentang dioper k kali
        lingkaran.append(lingkaran.popleft())   # yang depan pindah ke belakang
    print(lingkaran[0], "keluar")
    lingkaran.popleft()
print("Pemenang:", lingkaran[0])
```

```txt title="Output"
Dodi keluar
Citra keluar
Eka keluar
Budi keluar
Pemenang: Ani
```

Gerakan "keluar dari depan, masuk lagi di belakang" ini juga dipakai sistem operasi untuk berbagi prosesor secara bergiliran (_round-robin_): setiap program mendapat jatah waktu singkat, lalu kembali ke belakang antrean jika belum selesai. Kamu akan menyimulasikannya di latihan.

## Deque: antrean dua ujung

**Deque** (_double-ended queue_, dibaca "dek") adalah antrean yang bisa ditambah dan dikurangi di **kedua ujung**. Karena itu deque bisa berperan sebagai queue maupun stack. C++ menyediakannya di pustaka `<deque>`, sedangkan `deque` Python yang sudah kamu pakai memang deque sungguhan.

| Operasi | C++ `deque` | Python `deque` |
| --- | --- | --- |
| Tambah di depan | `d.push_front(x)` | `d.appendleft(x)` |
| Tambah di belakang | `d.push_back(x)` | `d.append(x)` |
| Buang dari depan | `d.pop_front()` | `d.popleft()` |
| Buang dari belakang | `d.pop_back()` | `d.pop()` |
| Lihat depan / belakang | `d.front()` / `d.back()` | `d[0]` / `d[-1]` |
| Elemen ke-`i` | `d[i]` | `d[i]` |

```cpp tab="C++"
#include <deque>

deque<int> d;
d.push_back(2);         // 2
d.push_back(3);         // 2 3
d.push_front(1);        // 1 2 3
d.push_front(0);        // 0 1 2 3
d.pop_back();           // 0 1 2
d.pop_front();          // 1 2

cout << d.front() << " " << d.back() << " " << d.size() << endl;   // 1 2 2
```

```python tab="Python"
from collections import deque

d = deque()
d.append(2)             # 2
d.append(3)             # 2 3
d.appendleft(1)         # 1 2 3
d.appendleft(0)         # 0 1 2 3
d.pop()                 # 0 1 2
d.popleft()             # 1 2

print(d[0], d[-1], len(d))   # 1 2 2
```

Berbeda dengan `queue`, `deque` C++ boleh diakses dengan indeks dan ditelusuri dengan for-each. Deque berguna saat kamu perlu membandingkan atau membuang data dari kedua sisi, misalnya memeriksa palindrom dari dua ujung, atau menyimpan riwayat terbatas: data baru masuk di belakang, data terlama dibuang dari depan. Python bahkan bisa membuang data terlama secara otomatis dengan `deque(maxlen=3)`.

## Antrean prioritas

Antrean di IGD rumah sakit tidak FIFO. Pasien yang paling gawat ditangani lebih dulu, walaupun datang belakangan. Struktur data untuk situasi ini disebut **antrean prioritas** (_priority queue_): setiap kali mengambil, yang keluar adalah elemen dengan prioritas tertinggi, bukan yang paling lama menunggu.

- **C++** menyediakan `priority_queue` di pustaka `<queue>`. Operasinya `push`, `pop`, `top` (bukan `front`), `empty`, dan `size`. Secara bawaan, yang keluar lebih dulu adalah elemen **terbesar**.
- **Python** menyediakan modul `heapq`, berisi fungsi-fungsi yang bekerja pada list biasa. Secara bawaan, yang keluar lebih dulu adalah elemen **terkecil**.

```cpp tab="C++"
#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

int main() {
    priority_queue<int> pq;                     // terbesar keluar dulu
    pq.push(30);
    pq.push(80);
    pq.push(50);
    while (!pq.empty()) {
        cout << pq.top() << " ";
        pq.pop();
    }
    cout << endl;                               // 80 50 30

    priority_queue<int, vector<int>, greater<int>> pqKecil;   // terkecil keluar dulu
    pqKecil.push(30);
    pqKecil.push(80);
    pqKecil.push(50);
    while (!pqKecil.empty()) {
        cout << pqKecil.top() << " ";
        pqKecil.pop();
    }
    cout << endl;                               // 30 50 80
    return 0;
}
```

```python tab="Python"
import heapq

pq = []                                     # list biasa
heapq.heappush(pq, 30)
heapq.heappush(pq, 80)
heapq.heappush(pq, 50)
while len(pq) > 0:
    print(heapq.heappop(pq), end=" ")       # terkecil keluar dulu
print()                                     # 30 50 80

# Agar terbesar keluar dulu: simpan nilai negatifnya
pq = []
for x in [30, 80, 50]:
    heapq.heappush(pq, -x)
while len(pq) > 0:
    print(-heapq.heappop(pq), end=" ")      # balik lagi tandanya
print()                                     # 80 50 30
```

| | C++ `priority_queue` | Python `heapq` |
| --- | --- | --- |
| Keluar lebih dulu (bawaan) | terbesar | terkecil |
| Tambah | `pq.push(x)` | `heapq.heappush(pq, x)` |
| Lihat berikutnya | `pq.top()` | `pq[0]` |
| Keluarkan | `pq.pop()` | `heapq.heappop(pq)`, sekaligus mengembalikan nilainya |
| Membalik urutan | `priority_queue<int, vector<int>, greater<int>>` | simpan `-x`, lalu balik tandanya saat keluar |

<Callout type="warning" title="Urutan bawaannya berlawanan">
  Saat menerjemahkan kode antrean prioritas dari C++ ke Python atau sebaliknya, ingat bahwa urutan bawaannya **berkebalikan**. Kode yang benar di satu bahasa akan mengambil elemen yang salah di bahasa lain jika diterjemahkan mentah-mentah.
</Callout>

Di dalamnya, kedua bahasa menyusun data dalam bentuk yang disebut **heap**: susunan khusus yang tidak sepenuhnya terurut, tetapi menjamin elemen berikutnya selalu ada di posisi pertama. Karena itu push dan pop tetap cepat walaupun datanya besar. Coba `print(pq)` setelah mem-push 30, 80, dan 50 di Python: hasilnya `[30, 80, 50]`, bukan `[30, 50, 80]`. Hanya `pq[0]` yang dijamin terkecil.

## Rangkuman

- Queue bekerja dengan aturan **FIFO**: elemen masuk dari belakang dan keluar dari depan, sehingga yang pertama masuk keluar pertama.
- C++: `queue` dari `<queue>` (`push`, `pop`, `front`, `back`). Python: `deque` dari `collections` (`append`, `popleft`, `[0]`, `[-1]`).
- `pop()` di C++ tidak mengembalikan nilai, sedangkan `popleft()` di Python mengembalikannya.
- Jangan pakai `list.pop(0)` atau `vector.erase(v.begin())` sebagai antrean untuk data besar, karena semua elemen lain harus digeser. Pakai `deque`.
- Periksa `empty()` sebelum `front()` atau `pop()`. Di C++ kesalahannya _undefined behavior_ yang bisa tampak normal, di Python menjadi `IndexError`.
- Deque bisa ditambah dan dikurangi di kedua ujung.
- Antrean prioritas mengeluarkan elemen berprioritas tertinggi. Bawaan C++ `priority_queue` adalah terbesar dulu, sedangkan Python `heapq` terkecil dulu.

  | Input | Output |
  | --- | --- |
  | `Kasur ini rusak` | `Palindrom` |

    ```cpp tab="C++"
                palindrom = false;
                break;
            }
            d.pop_front();
            d.pop_back();
        }

        if (palindrom) {
            cout << "Palindrom" << endl;
        } else {
            cout << "Bukan palindrom" << endl;
        }
        return 0;
    }
    ```

<Soal no={9} level="sulit" judul="Maksimum jendela geser">
  Baris pertama berisi `n` dan `k` (1 ≤ k ≤ n ≤ 100.000). Baris kedua berisi `n` bilangan bulat. Bayangkan sebuah "jendela" selebar `k` yang bergeser dari kiri ke kanan, satu posisi setiap langkah. Tampilkan nilai terbesar di dalam jendela untuk setiap posisinya (ada `n − k + 1` posisi), dipisah spasi.

  ```txt title="Contoh input 1"
  8 3
  4 2 12 3 8 1 7 5
  ```

  ```txt title="Contoh output 1"
  12 12 12 8 8 7
  ```

  ```txt title="Contoh input 2"
  5 1
  5 4 3 2 1
  ```

  ```txt title="Contoh output 2"
  5 4 3 2 1
  ```

  <Petunjuk>
    Mencari maksimum ulang untuk setiap jendela butuh `k` langkah per posisi, terlalu lambat untuk `n` dan `k` besar. Simpan **indeks** di deque dengan aturan: nilainya selalu menurun dari depan ke belakang. Sebelum memasukkan indeks `i`, buang dari belakang semua indeks yang nilainya tidak lebih besar dari `a[i]`. Buang dari depan indeks yang sudah keluar dari jendela. Maksimum jendela selalu ada di depan.
  </Petunjuk>

  <Pembahasan>
    Jika `a[i]` lebih besar atau sama dengan elemen lama di belakang deque, elemen lama itu tidak akan pernah menjadi maksimum lagi: `a[i]` lebih baru (bertahan lebih lama di jendela) dan setidaknya sama besar. Karena itu elemen lama aman dibuang. Setiap indeks masuk sekali dan keluar paling banyak sekali, jadi total kerjanya sebanding dengan `n`. Indeks disimpan, bukan nilai, agar kita tahu kapan sebuah elemen sudah keluar dari jendela (`indeks <= i - k`).

    ```cpp tab="C++"
    #include <iostream>
    #include <deque>
    #include <vector>
    using namespace std;

    int main() {
        int n, k;
        cin >> n >> k;
        vector<int> a(n);
        for (int i = 0; i < n; i++) {
            cin >> a[i];
        }

        deque<int> d;                        // indeks, nilainya menurun dari depan
        for (int i = 0; i < n; i++) {
            if (!d.empty() && d.front() <= i - k) {
                d.pop_front();               // sudah keluar dari jendela
            }
            while (!d.empty() && a[d.back()] <= a[i]) {
                d.pop_back();                // tidak akan pernah jadi maksimum lagi
            }
            d.push_back(i);

            if (i >= k - 1) {                // jendela sudah penuh
                if (i > k - 1) {
                    cout << " ";
                }
                cout << a[d.front()];
            }
        }
        cout << endl;
        return 0;
    }
    ```

Menggabungkan dua berkas berukuran `a` dan `b` membutuhkan waktu `a + b` dan menghasilkan satu berkas berukuran `a + b`. Berkas digabung dua-dua sampai tersisa satu. Tampilkan total waktu **paling kecil** yang mungkin.

  Baris pertama berisi `n`, baris kedua berisi ukuran setiap berkas. Jika hanya ada satu berkas, tidak ada yang perlu digabung dan jawabannya `0`.


  ```txt title="Contoh input 2"
  3
  5 5 5
  ```


  <Petunjuk>
    Berkas yang digabung lebih awal akan "terhitung lagi" di setiap penggabungan berikutnya, karena ia sudah menjadi bagian dari berkas yang lebih besar. Jadi berkas kecil sebaiknya digabung lebih dulu. Pakai antrean prioritas yang mengeluarkan yang **terkecil** dulu, dan perhatikan bahwa totalnya bisa melewati batas `int`.
  </Petunjuk>

  <Pembahasan>
    Selalu ambil dua berkas terkecil, gabungkan, lalu masukkan hasilnya kembali ke antrean. Untuk contoh 1:

    | Langkah | Diambil | Waktu | Isi antrean sesudahnya |
    | --- | --- | --- | --- |
    | 1 | 2 dan 3 | 5 | `4 5 6` |
    | 2 | 4 dan 5 | 9 | `6 9` |
    | 3 | 6 dan 9 | 15 | `15` |

    Totalnya 5 + 9 + 15 = 29. Urutan lain, misalnya (4 + 3), lalu (2 + 6), lalu (7 + 8), menghasilkan 7 + 8 + 15 = 30. Di C++ pakai `greater` agar terkecil keluar dulu, sedangkan di Python bawaan `heapq` sudah sesuai. Ukuran berkas bisa sampai 10<sup>9</sup>, jadi gunakan `long long`.

    ```cpp tab="C++"
    #include <iostream>
    #include <queue>
    #include <vector>
    #include <functional>
    using namespace std;

    int main() {
        int n;
        cin >> n;
        priority_queue<long long, vector<long long>, greater<long long>> pq;
        for (int i = 0; i < n; i++) {
            long long ukuran;
            cin >> ukuran;
            pq.push(ukuran);
        }

        long long total = 0;
        while (pq.size() > 1) {
            long long a = pq.top();
            pq.pop();
            long long b = pq.top();
            pq.pop();
            total += a + b;
            pq.push(a + b);
        }
        cout << total << endl;
        return 0;
    }
    ```
