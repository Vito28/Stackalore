## Masalah: adakah jalan dari A ke B?

Di materi [Graph](/docs/cpp/graph) kamu sudah bisa menyimpan graph sebagai adjacency list. Sekarang muncul pertanyaan yang lebih menarik: dari simpul 1, apakah simpul 5 bisa dicapai? Bagaimana dengan simpul 6?

```txt
1 ------- 2
|         | \
|         |   \
3 ------- 4 --- 5        6
```

Untuk graph sekecil ini, jawabannya terlihat dari gambar. Namun peta jalan sebuah kota bisa berisi puluhan ribu persimpangan, dan program tidak bisa "melihat gambar". Kita butuh cara yang sistematis untuk mengunjungi semua simpul yang bisa dicapai.

Bayangkan kamu menjelajahi labirin sambil membawa kapur. Di setiap persimpangan, kamu memilih lorong yang belum bertanda kapur, lalu terus berjalan **sejauh mungkin**. Jika buntu, atau semua lorong di depanmu sudah bertanda, kamu **mundur** ke persimpangan sebelumnya dan mencoba lorong lain di sana. Tanda kapur mencegahmu berputar-putar di tempat yang sama.

Cara menjelajah ini disebut **DFS** (_Depth-First Search_), penelusuran yang mengutamakan kedalaman. Di graph, "lorong" adalah sisi, "persimpangan" adalah simpul, dan "tanda kapur" adalah array `visited`.

## DFS rekursif

Langkah DFS dari sebuah simpul `u`:

1. Jika `u` sudah pernah dikunjungi, langsung kembali.
2. Tandai `u` sebagai sudah dikunjungi.
3. Untuk setiap tetangga `v` dari `u`, sesuai urutan di adjacency list, jalankan DFS dari `v`.

Langkah 3 memanggil DFS lagi dari dalam DFS, jadi bentuk paling alaminya adalah fungsi [rekursif](/docs/cpp/rekursi). Langkah 1 adalah kasus dasarnya. "Mundur" di labirin terjadi otomatis saat sebuah pemanggilan selesai dan kembali ke pemanggilnya.

```cpp tab="C++"
#include <iostream>
#include <vector>
using namespace std;

void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited) {
    if (visited[u]) {
        return;                              // kasus dasar: sudah pernah dikunjungi
    }
    visited[u] = true;                       // tandai SEBELUM masuk ke tetangga
    cout << u << " ";
    for (int v : adj[u]) {
        dfs(v, adj, visited);                // masuk sedalam mungkin lewat v
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    vector<bool> visited(n + 1, false);
    dfs(1, adj, visited);
    cout << endl;
    return 0;
}
```

Fungsi `dfs` menerima `adj` dan `visited` sebagai _reference_ (`&`), sehingga semua pemanggilan memakai array `visited` yang sama dan tidak ada yang disalin. Di Python, list memang selalu dioper sebagai referensi ke objek yang sama.

### Menelusuri jejaknya

Adjacency list untuk input di atas adalah `1: 2 3`, `2: 1 4 5`, `3: 1 4`, `4: 2 3 5`, `5: 2 4`, dan `6:` kosong. Setiap baris di bawah adalah satu pemanggilan `dfs`. Indentasinya menunjukkan siapa yang memanggil siapa.

```txt
dfs(1)                  kunjungi 1, tetangga: 2 3
├─ dfs(2)               kunjungi 2, tetangga: 1 4 5
│  ├─ dfs(1)            sudah dikunjungi, kembali
│  ├─ dfs(4)            kunjungi 4, tetangga: 2 3 5
│  │  ├─ dfs(2)         sudah dikunjungi, kembali
│  │  ├─ dfs(3)         kunjungi 3, tetangga: 1 4
│  │  │  ├─ dfs(1)      sudah dikunjungi, kembali
│  │  │  └─ dfs(4)      sudah dikunjungi, kembali
│  │  └─ dfs(5)         kunjungi 5, tetangga: 2 4
│  │     ├─ dfs(2)      sudah dikunjungi, kembali
│  │     └─ dfs(4)      sudah dikunjungi, kembali
│  └─ dfs(5)            sudah dikunjungi, kembali
└─ dfs(3)               sudah dikunjungi, kembali

Urutan kunjungan: 1 2 4 3 5
```

Perhatikan perjalanannya. Dari 1, DFS tidak memeriksa 2 dan 3 bergantian, tetapi langsung **masuk** ke 2, lalu dari 2 masuk ke 4, lalu dari 4 masuk ke 3. Di simpul 3 semua tetangga sudah dikunjungi (buntu), jadi DFS **mundur** ke 4 dan mencoba tetangga 4 berikutnya, yaitu 5. Simpul 3 akhirnya dicapai lewat 4, bukan langsung dari 1, karena saat `dfs(1)` sampai ke tetangga keduanya, simpul 3 sudah dikunjungi. Simpul 6 tidak pernah dikunjungi karena tidak ada sisi yang menuju ke sana.

Setiap pemanggilan yang belum selesai menunggu di **call stack**. Tabel berikut memperlihatkan isinya pada beberapa saat penting:

| Saat | Call stack (bawah → atas) |
| --- | --- |
| mengunjungi 1 | `dfs(1)` |
| mengunjungi 2 | `dfs(1) dfs(2)` |
| mengunjungi 4 | `dfs(1) dfs(2) dfs(4)` |
| mengunjungi 3 | `dfs(1) dfs(2) dfs(4) dfs(3)` |
| 3 buntu, mundur ke 4 | `dfs(1) dfs(2) dfs(4)` |
| mengunjungi 5 | `dfs(1) dfs(2) dfs(4) dfs(5)` |
| semua selesai | kosong |

Saat sebuah simpul dikunjungi, isi call stack sama dengan jalur dari simpul awal ke simpul itu, misalnya 1 → 2 → 4 → 3. "Mundur" berarti pemanggilan teratas selesai dan dikeluarkan dari call stack.

### Kenapa `visited` wajib ada?

Hapus pemeriksaan `visited`, dan lihat apa yang terjadi pada graph yang sama:

```cpp
void dfs(int u, const vector<vector<int>>& adj) {
    cout << u << " ";
    for (int v : adj[u]) {
        dfs(v, adj);                         // ✗ tanpa visited
    }
}
```

`dfs(1)` memanggil `dfs(2)`, yang tetangga pertamanya adalah 1, sehingga memanggil `dfs(1)` lagi, lalu `dfs(2)` lagi, dan seterusnya tanpa akhir. Program mencetak `1 2 1 2 1 2 ...` sampai call stack penuh. Versi C++ berhenti dengan `Segmentation fault` (stack overflow), sedangkan Python berhenti dengan `RecursionError: maximum recursion depth exceeded`.

Di graph tak berarah masalah ini selalu muncul, bahkan pada graph tanpa siklus: setiap sisi bisa dilewati bolak-balik. Di graph yang punya siklus, seperti 2 → 4 → 5 → 2, kamu bisa berputar terus walaupun tidak pernah berbalik arah. Array `visited` memastikan setiap simpul **hanya diproses sekali**.

### Variasi: periksa sebelum memanggil

Kamu akan sering menemukan DFS yang ditulis sedikit berbeda: pemeriksaan `visited` dipindahkan ke **sebelum** pemanggilan rekursif.

```cpp tab="C++"
void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited) {
    visited[u] = true;
    cout << u << " ";
    for (int v : adj[u]) {
        if (!visited[v]) {                   // hanya masuk ke tetangga yang belum dikunjungi
            dfs(v, adj, visited);
        }
    }
}
```

```python tab="Python"
def dfs(u, adj, visited):
    visited[u] = True
    print(u, end=" ")
    for v in adj[u]:
        if not visited[v]:                   # hanya masuk ke tetangga yang belum dikunjungi
            dfs(v, adj, visited)
```

Urutan kunjungannya sama persis. Bedanya, versi ini tidak membuat pemanggilan yang langsung kembali seperti `dfs(1)` di dalam `dfs(2)`. Kasus dasarnya tidak ditulis sebagai `if` tersendiri: jika semua tetangga `u` sudah dikunjungi, perulangan tidak memanggil apa-apa dan fungsi selesai. Bentuk ini berguna saat kamu perlu mengetahui **dari simpul mana** sebuah simpul ditemukan, seperti pada bagian mencatat jalan nanti. Pemanggil versi ini harus memastikan simpul awalnya belum dikunjungi.

## DFS dengan stack sendiri

Rekursi menyimpan "persimpangan yang belum selesai" di call stack. Kamu juga bisa menyimpannya sendiri di sebuah [Stack](/docs/cpp/stack), sehingga DFS menjadi perulangan biasa tanpa rekursi:

1. Push simpul awal.
2. Selama stack tidak kosong, pop sebuah simpul `u`.
3. Jika `u` sudah dikunjungi, lewati. Jika belum, tandai, lalu push semua tetangganya yang belum dikunjungi.

```cpp tab="C++"
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    vector<bool> visited(n + 1, false);
    stack<int> s;
    s.push(1);
    while (!s.empty()) {
        int u = s.top();
        s.pop();
        if (visited[u]) {
            continue;                        // sudah dikunjungi lewat jalan lain
        }
        visited[u] = true;
        cout << u << " ";
        for (int v : adj[u]) {
            if (!visited[v]) {
                s.push(v);
            }
        }
    }
    cout << endl;
    return 0;
}
```

```python tab="Python"
n, m = map(int, input().split())

    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

s = [1]                                      # list sebagai stack
while len(s) > 0:
    u = s.pop()
    if visited[u]:
        continue                             # sudah dikunjungi lewat jalan lain
    visited[u] = True
    print(u, end=" ")
    for v in adj[u]:
        if not visited[v]:
            s.append(v)
print()
```

Urutannya **berbeda** dari versi rekursif (`1 2 4 3 5`). Jejaknya:

| Pop | Tindakan | Stack sesudahnya (bawah → atas) |
| --- | --- | --- |
| | push 1 | `1` |
| 1 | kunjungi 1, push 2 dan 3 | `2 3` |
| 3 | kunjungi 3, push 4 | `2 4` |
| 4 | kunjungi 4, push 2 dan 5 | `2 2 5` |
| 5 | kunjungi 5, push 2 | `2 2 2` |
| 2 | kunjungi 2, semua tetangga sudah dikunjungi | `2 2` |
| 2 | sudah dikunjungi, lewati | `2` |
| 2 | sudah dikunjungi, lewati | kosong |

Penyebabnya sifat **LIFO**: simpul 1 mem-push 2 lalu 3, sehingga 3 yang keluar lebih dulu. Versi rekursif justru langsung masuk ke tetangga **pertama**. Keduanya tetap DFS yang sah, karena sama-sama masuk sedalam mungkin sebelum mundur. Hanya urutan memilih tetangganya yang terbalik.

Jika ingin urutan yang sama persis dengan versi rekursif, push tetangga dari yang **terakhir** ke yang pertama:

```cpp tab="C++"
for (int i = (int)adj[u].size() - 1; i >= 0; i--) {
    int v = adj[u][i];
    if (!visited[v]) {
        s.push(v);
    }
}
```

```python tab="Python"
for v in reversed(adj[u]):                   # dari tetangga terakhir ke pertama
    if not visited[v]:
        s.append(v)
```

Perhatikan juga bahwa simpul 2 sempat berada di stack tiga kali. Simpul baru ditandai saat di-pop, jadi simpul yang sama bisa di-push oleh beberapa tetangga sebelum giliran dikunjunginya tiba. Karena itu pemeriksaan `if (visited[u]) continue;` setelah pop **wajib** ada.

Untuk pertanyaan yang tidak bergantung pada urutan, seperti "bisa dicapai atau tidak?" atau "ada berapa komponen?", versi rekursif dan versi stack memberi jawaban yang sama. Versi stack tidak dibatasi kedalaman call stack, sehingga aman untuk graph yang sangat besar.

## Penerapan DFS

### Apakah ada jalan dari a ke b?

Jalankan DFS dari `a`. Setelah selesai, `visited` berisi `true` untuk setiap simpul yang bisa dicapai dari `a`. Jadi cukup periksa `visited[b]`.

```cpp tab="C++"
vector<bool> visited(n + 1, false);
dfs(a, adj, visited);
if (visited[b]) {
    cout << "Ada jalan" << endl;
} else {
    cout << "Tidak ada jalan" << endl;
}
```

```python tab="Python"
visited = [False] * (n + 1)
dfs(a, adj, visited)
if visited[b]:
    print("Ada jalan")
else:
    print("Tidak ada jalan")
```

Pada graph contoh, DFS dari 1 menandai simpul 1 sampai 5, sehingga ada jalan dari 1 ke 5, tetapi tidak ada jalan dari 1 ke 6.

### Menghitung komponen terhubung

Satu kali DFS mengunjungi **satu komponen** utuh, yaitu semua simpul yang bisa dicapai dari simpul awal. Untuk menghitung komponen, coba setiap simpul dari 1 sampai `n`. Simpul yang belum dikunjungi pasti milik komponen baru, jadi tambah penghitung lalu jalankan DFS dari sana untuk menandai seluruh komponennya.

```cpp tab="C++"
#include <iostream>
#include <vector>
using namespace std;

void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited) {
    if (visited[u]) {
        return;                              // kasus dasar
    }
    visited[u] = true;
    for (int v : adj[u]) {
        dfs(v, adj, visited);
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    vector<bool> visited(n + 1, false);
    int komponen = 0;
    for (int u = 1; u <= n; u++) {
        if (!visited[u]) {
            komponen++;                      // u belum terjangkau: komponen baru
            dfs(u, adj, visited);            // tandai seluruh komponen milik u
        }
    }
    cout << komponen << endl;
    return 0;
}
```

### Mencatat jalannya dengan array induk

`visited` hanya menjawab "bisa atau tidak". Untuk mengetahui **jalannya**, catat dari simpul mana setiap simpul pertama kali ditemukan. Catatan ini disebut **induk** (_parent_). Di sinilah variasi "periksa sebelum memanggil" berguna, karena di titik itu kita tahu `v` ditemukan dari `u`.

Setelah DFS selesai, jalannya dibaca **mundur**: mulai dari `b`, ikuti `induk` sampai tiba di `a`, lalu balik urutannya.

```cpp tab="C++"
#include <iostream>
#include <vector>
using namespace std;

void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited, vector<int>& induk) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (!visited[v]) {
            induk[v] = u;                    // v pertama kali ditemukan dari u
            dfs(v, adj, visited, induk);
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    int a, b;
    cin >> a >> b;

    vector<bool> visited(n + 1, false);
    vector<int> induk(n + 1, 0);             // 0 berarti tidak punya induk
    dfs(a, adj, visited, induk);

    if (!visited[b]) {
        cout << "Tidak ada jalan" << endl;
        return 0;
    }
    vector<int> jalan;
    for (int x = b; x != 0; x = induk[x]) {  // mundur dari b sampai a
        jalan.push_back(x);
    }
    for (int i = (int)jalan.size() - 1; i >= 0; i--) {   // cetak dari a ke b
        cout << jalan[i] << " ";
    }
    cout << endl;
    return 0;
}
```


Dari jejak sebelumnya, `induk[2] = 1`, `induk[4] = 2`, `induk[3] = 4`, dan `induk[5] = 4`. Mundur dari 5: 5 → 4 → 2 → 1, lalu dibalik menjadi `1 2 4 5`. Simpul awal `a` tidak pernah mendapat induk, jadi nilainya tetap 0 dan perulangan berhenti di sana.

Perhatikan bahwa jalan ini **bukan yang terpendek**. Jalan 1 → 2 → 5 hanya melewati dua sisi, tetapi DFS terlanjur masuk ke 4 sebelum mencoba sisi 2–5. DFS menjamin menemukan **sebuah** jalan, tidak menjamin yang terpendek.

### Flood fill: menghitung ruangan

Di [Graph](/docs/cpp/graph) kamu melihat bahwa [grid](/docs/cpp/matriks) adalah graph: setiap sel adalah simpul, dan tetangganya adalah sel di atas, bawah, kiri, dan kanan. DFS pada grid disebut **flood fill**, seperti menuang cat di satu sel lalu membiarkannya menyebar ke semua sel terbuka yang tersambung. Fitur "ember cat" di aplikasi menggambar bekerja dengan cara ini.

Contoh: sebuah denah berisi `.` untuk lantai dan `#` untuk dinding. Berapa banyak ruangan, yaitu kelompok lantai yang tersambung? Ini sama dengan menghitung komponen, hanya simpulnya berupa sel.

```cpp tab="C++"
#include <iostream>
#include <string>
#include <vector>
using namespace std;

void isi(int i, int j, const vector<string>& grid, vector<vector<bool>>& visited) {
    int r = grid.size();
    int c = grid[0].size();
    if (i < 0 || i >= r || j < 0 || j >= c) {
        return;                              // kasus dasar: di luar denah
    }
    if (grid[i][j] == '#' || visited[i][j]) {
        return;                              // kasus dasar: dinding atau sudah dikunjungi
    }
    visited[i][j] = true;

    int dr[4] = {-1, 1, 0, 0};               // atas, bawah, kiri, kanan
    int dc[4] = {0, 0, -1, 1};
    for (int d = 0; d < 4; d++) {
        isi(i + dr[d], j + dc[d], grid, visited);
    }
}

int main() {
    int r, c;
    cin >> r >> c;
    vector<string> grid(r);
    for (int i = 0; i < r; i++) {
```

### Mendeteksi siklus di graph tak berarah

Saat DFS berada di `u` dan menemukan tetangga `v` yang **sudah dikunjungi**, artinya `v` bisa dicapai lewat dua jalan: jalan yang dulu dipakai untuk mengunjungi `v`, dan jalan yang sekarang tiba di `u`. Dua jalan itu membentuk siklus.

Ada satu pengecualian. Di graph tak berarah, simpul yang baru saja kita tinggalkan untuk datang ke `u`, yaitu induknya, pasti sudah dikunjungi. Sisi `u`–induk adalah sisi yang sama yang baru dilewati, bukan siklus. Karena itu induknya dilewati.

```cpp tab="C++"
#include <iostream>
#include <vector>
using namespace std;

bool adaSiklus(int u, int induk, const vector<vector<int>>& adj, vector<bool>& visited) {
    visited[u] = true;
    for (int v : adj[u]) {
        if (v == induk) {
            continue;                        // sisi yang baru saja dilewati, bukan siklus
        }
        if (visited[v]) {
            return true;                     // simpul lama ditemui lewat jalan lain
        }
        if (adaSiklus(v, u, adj, visited)) {
            return true;
        }
    }
    return false;
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    bool siklus = false;
```

## Kompleksitas DFS

Setiap simpul ditandai dan diproses paling banyak sekali, dan setiap isi adjacency list diperiksa paling banyak sekali (setiap sisi tak berarah tercatat dua kali). Jadi total kerja DFS dengan adjacency list adalah **O(n + m)**: sebanding dengan banyak simpul ditambah banyak sisi. Untuk grid berukuran `r × c`, kerjanya O(r × c).

Jika graph disimpan sebagai adjacency matrix, mencari tetangga setiap simpul butuh memeriksa satu baris penuh, sehingga DFS menjadi O(n²). Ini salah satu alasan adjacency list lebih disukai untuk penelusuran. Lihat <Term href="/docs/cpp/pendalaman/kompleksitas-waktu">kompleksitas waktu</Term> untuk arti notasi ini.

## DFS pada tree

Kamu sebenarnya sudah pernah menulis DFS. Penelusuran **preorder** di materi [Tree](/docs/cpp/tree) adalah DFS yang dimulai dari root: kunjungi node, lalu masuk sedalam mungkin ke subtree kiri, baru setelah itu ke subtree kanan.

```cpp tab="C++"
void cetakPreorder(Node* root) {
    if (root == nullptr) {
        return;                              // kasus dasar
    }
    cout << root->data << " ";               // kunjungi node ini dulu
    cetakPreorder(root->left);               // masuk sedalam mungkin ke kiri
    cetakPreorder(root->right);              // baru ke kanan
}
```

```python tab="Python"
def cetak_preorder(root):
    if root is None:
        return                               # kasus dasar
    print(root.data, end=" ")                # kunjungi node ini dulu
    cetak_preorder(root.left)                # masuk sedalam mungkin ke kiri
    cetak_preorder(root.right)               # baru ke kanan
```

Preorder tidak butuh `visited` karena tree tidak punya siklus dan pointer `left`/`right` hanya mengarah ke bawah, tidak pernah kembali ke induk. Namun jika sebuah tree disimpan sebagai graph tak berarah dengan adjacency list, `visited` (atau pemeriksaan induk) tetap dibutuhkan, karena dari anak kamu bisa berjalan kembali ke induknya.

## Kesalahan yang sering terjadi

### Lupa `visited`

Sudah dibahas di atas: tanpa `visited`, DFS bolak-balik di sisi yang sama sampai call stack penuh. Python menampilkan `RecursionError`, C++ biasanya crash dengan `Segmentation fault`. Jika program DFS-mu tiba-tiba crash, periksa dulu apakah setiap simpul ditandai.

### Menandai `visited` terlambat

Menandai simpul **setelah** menelusuri tetangganya sama buruknya dengan tidak menandai sama sekali:

```cpp
void dfs(int u, const vector<vector<int>>& adj, vector<bool>& visited) {
    if (visited[u]) {
        return;
    }
    for (int v : adj[u]) {
        dfs(v, adj, visited);                // ✗ u belum ditandai, tetangganya bisa kembali ke u
    }
    visited[u] = true;                       // terlambat
}
```

Saat `dfs(2)` memanggil `dfs(1)`, simpul 1 belum ditandai, sehingga rekursinya tidak pernah berhenti. Aturannya: **tandai dulu, baru telusuri tetangga**.

Di versi stack, simpul memang baru ditandai saat di-pop, sehingga simpul yang sama bisa berada di stack beberapa kali. Jika lupa memeriksa `visited` setelah pop, simpul itu diproses berkali-kali. Pada contoh tadi, output-nya menjadi `1 3 4 5 2 2 2`.

### Rekursi terlalu dalam

Setiap pemanggilan rekursif memakai sedikit ruang di call stack. Pada graph berbentuk rantai panjang (1–2, 2–3, 3–4, dan seterusnya), DFS dari simpul 1 menumpuk satu pemanggilan untuk setiap simpul sebelum ada yang selesai.

- **Python** membatasi kedalaman rekursi sekitar 1000 pemanggilan. DFS rekursif pada rantai berisi 1000 simpul sudah berhenti dengan `RecursionError`.
- **C++** tidak punya batas jumlah pemanggilan, tetapi ukuran call stack terbatas, biasanya 1 sampai 8 MB. Pada satu percobaan di Linux dengan stack 8 MB, DFS rekursif pada rantai 100.000 simpul sudah crash dengan `Segmentation fault`.

Untuk graph yang bisa sangat besar, pakai DFS dengan stack sendiri, atau BFS yang juga memakai perulangan. Latihan di bawah sengaja memakai graph kecil sehingga versi rekursif aman di kedua bahasa.

## DFS tidak mencari jalan terpendek

DFS menjawab "bisa atau tidak", menghitung komponen, dan menemukan siklus dengan sangat baik. Namun seperti contoh jalan 1 → 2 → 4 → 5 tadi, jalan yang ditemukan DFS bergantung pada urutan tetangga dan sering berputar jauh. Untuk mencari jalan dengan **sisi paling sedikit**, misalnya langkah minimal keluar dari labirin, gunakan [BFS](/docs/cpp/bfs), yang menyebar dari titik awal lapis demi lapis.

## Rangkuman

- **DFS** menelusuri graph dengan masuk sedalam mungkin lewat tetangga yang belum dikunjungi, lalu mundur saat buntu.
- Versi rekursif: kasus dasarnya "sudah dikunjungi, kembali". Tandai `visited[u]` **sebelum** menelusuri tetangga. Isi call stack selalu jalur dari simpul awal ke simpul yang sedang dikunjungi.
- Tanpa `visited`, DFS berputar selamanya, bahkan di graph tak berarah tanpa siklus.
- Versi stack memakai `stack` (C++) atau list (Python). Simpul ditandai saat di-pop, jadi periksa `visited` setelah pop. Urutannya bisa berbeda dari versi rekursif karena sifat LIFO, kecuali tetangga di-push dari belakang.
- Penerapan: memeriksa jalan dari `a` ke `b`, menghitung komponen, mencatat jalan dengan array induk, flood fill pada grid, dan mendeteksi siklus di graph tak berarah dengan pemeriksaan induk.
- Kompleksitas DFS dengan adjacency list adalah O(n + m). Preorder pada tree adalah DFS.
- Rekursi yang terlalu dalam membuat program crash. Untuk graph raksasa, pakai versi stack.
- Jalan yang ditemukan DFS belum tentu terpendek. Untuk jalan terpendek, pakai BFS.

<Soal no={9} level="sulit" judul="Siklus di graph berarah">
  Baca sebuah graph **berarah** (baris `u v` berarti panah dari `u` ke `v`). Tampilkan `YA` jika graph itu punya siklus berarah, yaitu jalur yang mengikuti arah panah dan kembali ke simpul awalnya, atau `TIDAK` jika tidak ada.

  ```txt title="Contoh input"
  4 4
  1 2
  1 3
  3 2
  2 4
  ```

  ```txt title="Contoh output"
  TIDAK
  ```

  ```txt title="Contoh input 2"
  4 4
  1 2
  2 3
  3 4
  4 2
  ```

  ```txt title="Contoh output 2"
  YA
  ```

  <Petunjuk>
    Cara untuk graph tak berarah ("ketemu simpul yang sudah dikunjungi berarti siklus") memberi jawaban salah pada contoh 1. Bedakan tiga keadaan simpul: **belum dikunjungi**, **sedang ditelusuri** (pemanggilannya masih di call stack), dan **selesai**. Siklus hanya ada jika DFS tiba di simpul yang sedang ditelusuri.
  </Petunjuk>

  <Pembahasan>
    Pada contoh 1, DFS dari 1 menelusuri 1 → 2 → 4, lalu mundur. Saat kemudian menelusuri 1 → 3 → 2, simpul 2 sudah dikunjungi. Namun 2 sudah **selesai**, dan dari 2 tidak ada jalan kembali ke 3, jadi ini bukan siklus. Hanya dua jalan berbeda yang bertemu di simpul yang sama.

    Simpul yang **sedang ditelusuri** adalah simpul di call stack, yaitu jalur dari simpul awal ke simpul sekarang. Jika dari `u` ada panah ke simpul seperti itu, panah tersebut menutup jalur menjadi lingkaran. Pada contoh 2, saat DFS berada di 4 (call stack 1 → 2 → 3 → 4), panah 4 → 2 menuju simpul yang masih sedang ditelusuri, sehingga ada siklus 2 → 3 → 4 → 2.

    Status diberi nilai 0 (belum), 1 (sedang), atau 2 (selesai). Sebuah simpul berubah dari 1 menjadi 2 tepat sebelum pemanggilannya selesai, yaitu saat ia keluar dari call stack. DFS harus dicoba dari setiap simpul yang masih berstatus 0, karena siklus bisa saja tidak terjangkau dari simpul 1.

    ```cpp tab="C++"
    #include <iostream>
    #include <vector>
    using namespace std;

    // status: 0 = belum dikunjungi, 1 = sedang ditelusuri, 2 = selesai
    bool adaSiklus(int u, const vector<vector<int>>& adj, vector<int>& status) {
        if (status[u] == 1) {
            return true;                     // kasus dasar: kembali ke simpul di call stack
        }
        if (status[u] == 2) {
            return false;                    // kasus dasar: sudah tuntas diperiksa
        }
        status[u] = 1;
        for (int v : adj[u]) {
            if (adaSiklus(v, adj, status)) {
                return true;
            }
        }
        status[u] = 2;                       // keluar dari call stack
        return false;
    }

    int main() {
        int n, m;
        cin >> n >> m;
        vector<vector<int>> adj(n + 1);
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            adj[u].push_back(v);
        }

        vector<int> status(n + 1, 0);
        bool siklus = false;
        for (int u = 1; u <= n; u++) {
            if (status[u] == 0 && adaSiklus(u, adj, status)) {
                siklus = true;
                break;
            }
        }

        if (siklus) {
            cout << "YA" << endl;
        } else {
            cout << "TIDAK" << endl;
        }
        return 0;
    }
    ```

    Untuk setiap mata kuliah `v`, hitung semester paling awal ia bisa diambil. Mata kuliah tanpa prasyarat bisa diambil di semester 1. Selain itu, `v` bisa diambil satu semester setelah prasyaratnya yang **paling akhir**. Simpan daftar prasyarat setiap mata kuliah (balik arah panahnya), lalu hitung secara rekursif. Simpan hasilnya agar setiap mata kuliah hanya dihitung sekali.
  </Petunjuk>

  <Pembahasan>
    Misalkan `semester(v)` adalah semester paling awal `v` bisa diambil. Maka `semester(v) = 1 + semester terbesar di antara prasyarat v`, atau 1 jika `v` tidak punya prasyarat. Jika setiap mata kuliah diambil di semester paling awalnya, semua aturan terpenuhi, jadi jawabannya adalah nilai `semester(v)` terbesar. Tidak ada jadwal yang lebih cepat, karena rantai prasyarat terpanjang (1 → 2 → 4 → 5 pada contoh 1) harus diambil satu per satu di semester yang berbeda.

    | Mata kuliah | Prasyarat | Semester paling awal |
    | --- | --- | --- |
    | 1 | | 1 |
    | 3 | | 1 |
    | 2 | 1 | 2 |
    | 6 | 1 | 2 |
    | 4 | 2, 3 | 3 |
    | 5 | 4 | 4 |

    Fungsinya adalah DFS mengikuti panah prasyarat ke belakang, dengan array `memo` sebagai pengganti `visited`: nilai 0 berarti belum dihitung. Tanpa `memo`, mata kuliah yang menjadi prasyarat banyak mata kuliah lain akan dihitung berulang kali, dan pada graph tertentu banyak pemanggilannya bisa meledak secara eksponensial. Dengan `memo`, setiap simpul dihitung sekali, jadi totalnya O(n + m). Teknik menyimpan hasil pemanggilan rekursif seperti ini dibahas di [Memoisasi](/docs/cpp/pendalaman/memoisasi).

    ```cpp tab="C++"
    #include <algorithm>
    #include <iostream>
    #include <vector>
    using namespace std;

    int semester(int v, const vector<vector<int>>& prasyarat, vector<int>& memo) {
        if (memo[v] != 0) {
            return memo[v];                  // kasus dasar: sudah pernah dihitung
        }
        int palingAkhir = 0;                 // semester prasyarat yang paling akhir
        for (int u : prasyarat[v]) {
            palingAkhir = max(palingAkhir, semester(u, prasyarat, memo));
        }
        memo[v] = palingAkhir + 1;           // tanpa prasyarat: semester 1
        return memo[v];
    }

    int main() {
        int n, m;
        cin >> n >> m;
        vector<vector<int>> prasyarat(n + 1);
        for (int i = 0; i < m; i++) {
            int u, v;
            cin >> u >> v;
            prasyarat[v].push_back(u);       // simpan arah balik: v butuh u
        }

        vector<int> memo(n + 1, 0);
        int jawaban = 0;
        for (int v = 1; v <= n; v++) {
            jawaban = max(jawaban, semester(v, prasyarat, memo));
        }
        cout << jawaban << endl;
        return 0;
    }
    ```

    ```python tab="Python"
    def semester(v, prasyarat, memo):
        if memo[v] != 0:
            return memo[v]                   # kasus dasar: sudah pernah dihitung
        paling_akhir = 0                     # semester prasyarat yang paling akhir
        for u in prasyarat[v]:
            paling_akhir = max(paling_akhir, semester(u, prasyarat, memo))
        memo[v] = paling_akhir + 1           # tanpa prasyarat: semester 1
        return memo[v]


    n, m = map(int, input().split())
    prasyarat = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        prasyarat[v].append(u)               # simpan arah balik: v butuh u

    memo = [0] * (n + 1)
    jawaban = 0
    for v in range(1, n + 1):
        jawaban = max(jawaban, semester(v, prasyarat, memo))
    print(jawaban)
    ```

    Urutan mata kuliah yang memenuhi semua prasyarat, seperti 1, 3, 2, 6, 4, 5, disebut **urutan topologis**. Mengambil mata kuliah per semester seperti tabel di atas adalah salah satu cara menyusunnya.
